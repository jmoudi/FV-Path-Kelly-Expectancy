# kit/state

- `createAppStore.ts`: `createAppStore<P, D>(config)`, one zustand store: params with undo and redo, imported number lists, chart overrides and stories (one parameter-moving story at a time, its snapshot persisted), sweep presets, links, runs and the values before them, UI settings, parameter settings (`paramSettings`: key → how that parameter is edited by hand; `setParamSettings(key, patch)` with null clearing a field, `resetParamSettings(key?)`; the sweeps never read them), persistence under `storageKey`, versioned import and export, everything sanitized on load. An import without `paramSettings` (an older export) keeps the current ones; `resetEverything` clears them, `resetParams` does not.
- Locks: `locks` (key → true; a key of the schema or a linked key the config's `constraints.linked` names), `lockParam(key, on)`, `unlockAll()`, `lockLabel(key)`, persisted and exported, sanitized on load and import. Every change of the parameters (hand, sweep tick, story, switch, linked value, action, undo, redo, the resets, an import) runs through one step, `applyConstraints(prev, patch, locks, source, opts)` (`constraints.ts`, pure and worker-safe): a locked key is refused, the relations of `constraints.relations` run until nothing moves (a key one relation set is pinned for the others; `maxPasses`, default 8, is the cycle guard), and the store applies the patch it returns and emits `param:refused` for each refusal (with `by`, the lock that blocks it, and `detail`). `setParams` returns `{ refused }`; `checkChange(patch)` and `storyRefusals(chartId, story)` answer without changing anything. A switch, a story, a linked value, an action and each value of a sweep tick are all or nothing. The planner is never called for a locked key; locking stops a run on it (or one whose next value the new locks refuse) with `sweep:stopped` reason `lock`, and so does a refused tick, for its own run only. An import keeps a locked value and adds the file's locks (an older file without them keeps the current ones); `resetEverything` clears them, `resetParams` and Reset chart edits keep locked values.
- Events: every action that changes something emits on the event bus (`kit/events`) once the new state is set: `param:changed` per parameter that moved, with its source (`setParam(key, value, source?)` and `setParams(patch, { source })`; a sweep tick is `"sweep"`, undo `"undo"`, an import `"import"`, a story `"story"`, …), `sweep:started|paused|stopped` (with the reason), `story:applied|cleared` (with the values before and after), `chart:edited`, `data:changed`, `state:imported` (also when refused), `state:reset`, `settings:changed`, `param:locked`, `param:refused`. The bus comes in the config (`bus`) or through `connectBus(bus)`; `getBus()` reads it. Without one nothing is emitted.
- `context.tsx`: `<KitProvider store schema sweeps copy bus>`, and `useKit(selector)`, `useKitApi()`, `useSchema()`, `useKitSweeps()`, `useKitCopy()` for kit components; it renders the `BusProvider` and connects the store to the bus. Kit components see the erased types (`KitState<any, any>`, `Schema<any>`); the app keeps its own typed `useStore`.

What the app supplies: `{ schema, datasets: { empty, sanitize }, storageKey, version, presets: { defaults, legacy? }, planner?, bus?, constraints? }`, where `planner` is `plannerFor(adapter)` from `kit/sweeps/adapter.ts` and `constraints` the relations and linked keys. In this app: `src/app/store.ts` (export version 6, with `CONSTRAINTS` from `src/app/data/constraints.ts`); the bus arrives through `<KitProvider bus>` in `src/main.tsx`.
